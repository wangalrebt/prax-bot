Run a shell command in the workspace, starting at the repository root or the supplied workdir; shell tools such as ls, find, grep and git go through here. Returns the exit code and output tail; full output is saved at the reported path. Read that log instead of rerunning a command just to see earlier output. Each completed run creates a checkpoint. With original set, the command runs in a throwaway copy where the repository is as it was before your changes, with the same scratch files and installed packages; nothing it does is kept. Execution boundaries and scratch paths are described in the system message.
